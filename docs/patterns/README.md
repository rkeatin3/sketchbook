# Design Patterns

Patterns from Gamma et al. and Iglberger's *C++ Software Design*, implemented
in modern C++ and, where possible, motivated by a real need arising in the
robotics modules rather than a toy example.

Each pattern gets a single page covering: the problem it solves, the classical
formulation, the modern C++ formulation, the trade-offs, and where it appears
in this repository.
