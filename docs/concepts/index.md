# Concepts

Articles on ideas that are used across modules but have no implementation of
their own in this repository: probability and linear-algebra background,
measure-theoretic results, and similar foundations.

If a concept later gains code, its article moves next to that code. References
to it use its label (see {doc}`/docs/conventions/index`), so nothing that links
to it breaks.
