# Utilities

General-purpose building blocks: data structures and concurrency primitives,
implemented by hand to understand how they work and why they're correct. Like
the robotics modules, they favor clarity over performance, and each gets
articles covering its invariants, its complexity, and (where threads are
involved) its memory-ordering argument.
